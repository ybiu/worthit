ROI 与限制 / ROI and Limits

定性判断 / Qualitative. 当前不计算 monetary ROI、净价值或 benefit/cost ratio，因为 AI 用量、模型价格、人工成本和收益估计都不具备可防御的数值基础。

最大限制：不能用“写了多少代码”“用了多少 token”直接替代价值。当前证据只能说明 WorthIt Skill 已经形成可用的评估机制，不能证明它或被评估项目已经带来财务回报。

  • 缺少本次 Codex 对话的 provider-reported input/output token 和账单。
  • 缺少人工工时、费率以及旧流程基线。
  • 缺少 Skill 的安装后使用次数、报告采纳率和用户反馈。
  • 本次无法确认旧 Web 项目是否仍属于当前仓库或是否可复现运行。

下一步最小测量 / Minimum Next Measurement

记录一次真实使用样本：保存 Codex 的输入/输出 token、模型与账单，记录人工复核工时，并让一名真实用户用报告做出一个可验证决策。若该样本能证明报告节省了时间、减少了返工，或支持继续投入，结论可从 promising 提升为更强的正向判断。
